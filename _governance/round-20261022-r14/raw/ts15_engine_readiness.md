1. Add product-level typed Kind/Host/Mode eligibility inputs to the thin SBL adapter, keeping Source/PI/PD/ECP ownership with PIPD and all normative WorkOrder/RoleBinding/Lease/result operations in existing HGK.
2. Turn supplied goal/clauses into source-bound per-product requirements/ACC and obtain the existing native admitted write scope. Refuse exact unsupported Kind/Host or missing authority before creating effects; do not convert SKILL into AGENT_SKILL implicitly.
3. Bind a real bounded writer capable of emitting fresh code/tests/package metadata; SBLM04 only hands off and reports native result/readback. No second issuer/permit/dispatcher.
4. Execute real tests, preserve FirstFail and minimal impacted graph closure, make one cap=1 repair candidate if permitted, run affected and global tests. Native budget enforcement and digest-checked checkpoint/replay must be implemented by the owning native surface; TS16 identifies current gaps.
5. Install each newly generated artifact on the admitted actual Host, observe FUO and deny/off/stop behavior, then uninstall/read back residue. Pass only subject-bound raw evidence to a distinct-principal checker and the legitimate Owner.

# R14-TS08 — HGK native upgrade delta (typed ABI)

Measured 2026-10-22 · source of numbers: `raw/capability_delta.json` (generated by `hg_kseos.capability_delta.compute`)
Oracle: `tests/test_capability_delta.py` — 7 passed (apply atomicity, replay, expiry, partial-effect rollback,
schema/empty refusal, typed denied receipt, and the classification carries evidence).

## 1. What this ABI answers

| question | field |
|---|---|
| can HGK reuse this capability as it stands? | `rows[].state == REUSE_AS_IS` |
| does it need an adapter first? | `rows[].adapter_required` |
| is it absent? | `state == MISSING` |
| does it need a native upgrade (i.e. a scoped root WO)? | `state == NEEDS_NATIVE_UPGRADE` |

An adapter's `install`/`doctor` output is **not** evidence of a native capability; `adapter_is_not_a_native_upgrade`
is a constant `true` in every delta so a downstream consumer cannot read the delta as a claim that wrapping = upgrading.

The 31 are **test debt, not upgrade work** — they do not justify a root WO, and they are listed by name in the JSON
so they cannot be mistaken for a green surface.

**Calibration note (recorded because it changes the verdict).** The first instrument run reported three
`NEEDS_NATIVE_UPGRADE` rows. They were false: the symbol names (`resolve_route`, `admit`, `validate_transition`) were
invented rather than read from the modules. After calibration the count is zero. A measuring device that has not been
calibrated manufactures work — this is why the delta carries the module path and the exact `def` line for every row.

## 3. Application semantics (the four negatives the order demands)

| case | code | behaviour |
|---|---|---|
| replay | `ERR_DELTA_REPLAY` | a nonce already applied is refused before any write |
| expiry | `ERR_DELTA_EXPIRED` | `expires_at < now` refused before any write |
| partial effect | `ERR_DELTA_PARTIAL_EFFECT` | an item failing mid-apply rolls back every applied item and names them; the spine keeps 0 rows |
| rollback | `HGK-DELTA-ROLLED-BACK/1` | every applied delta returns `RB-<delta_id>` which removes exactly its items |

All four are asserted in `tests/test_capability_delta.py`, and the partial-effect test asserts the *spine state*
(0 items, 0 deltas), not just the exception code.

## 4. Ceiling

This closes TS08 at the level it was written: a typed delta plus enforced negatives. It does **not** upgrade any
code and does **not** clear the 31 untested functions. No root WO was opened because nothing measured as
`NEEDS_NATIVE_UPGRADE`; if a later item turns one up, the rule is that only a scoped HGK root WorkOrder may fix it.

## 9. Traps paid for this session — do not pay again

1. **Overlapping timestamps are not causation.** I accused the lanes, then two Kanban tasks, and was wrong twice: the
   writer was a **sibling governed round `W2-MATRIX-CLOSURE-20261023`** (board task `t_6feeeead`, its own
   `MANDATE_W2.json`, pool rev21, citing this round's `EXECUTE__BRIEF4.json`). Check `HG-KSEOS/var/*/MANDATE_*.json`
   before calling a writer unauthorised, and never delete its files or kill its workers — two of its codex runs were
   lost that way and had to be disclosed.
2. **An arm that produces artefacts but never terminates is a brief problem, not a model problem.** 540 s and 600 s
   timeouts shared one property: an open-ended deliverable list. A four-file minimum-output brief finished in 557 s
   green. Cut the list before raising the budget; never re-dispatch an unchanged brief a third time.
3. **`rc=$?` after a pipeline is the last command's status.** `… | head` made a failing guard look green.
4. **heredoc `\n` becomes a real newline.** It silently produced a `SyntaxError` that stopped a dispatch before it
   started, and I reported the lane as failing. Use `chr(10)` or write files with the file tools.
5. **MSYS `/tmp` is invisible to native git.** A credential-store file there made `GIT_ASKPASS` useless while the
   earlier "success" was GCM's cache. Use a native path.
6. **Never let git ask.** `credential.interactive=always` pops the GitHub login window — that is what a user sees.
   Use `tools/push_pat.sh`: PAT → credential-store at a native path → `credential.interactive=never` →
   `GIT_TERMINAL_PROMPT=0`, with a lookup self-check before pushing.
7. **A register that only stores status is a report, not infrastructure.** Queue items carry `resume_cmd`, `expect`,
   `timeout_s`, `owner_class`, `principal_request_ref`.
8. **"Queue exhausted" ≠ "task complete".** `QUEUE_EXHAUSTION_PROOF.json` says `r15_2_complete: false` on purpose.
9. **Negative-control your guards.** `guard_negative_control.py` found `satisfiable_by` was only checked on PARKED
   items; the guard was silently weaker than its name.
10. **Snapshot the control plane around every dispatch.** `run_lane` does it now and writes
    `LANE_TOUCHED_CONTROL_PLANE`; a write-set is a declaration, and `danger-full-access` ignores declarations.
11. **`hermes` trampoline is broken on this host** (`uv trampoline failed to canonicalize script path`). Use
    `./venv/Scripts/python.exe -m hermes_cli.main …` from `…/hermes/hermes-agent`.
